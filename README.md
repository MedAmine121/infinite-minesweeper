# Infinite Minesweeper

Infinite Minesweeper is a browser-based puzzle game built with Angular. The board is generated as a collection of connected grids, and players can reveal cells, place flags, pan around the world, and zoom in or out while managing a limited number of lives.

## Features

- Reveal safe cells and uncover adjacent counts
- Place and remove flags with the right mouse button
- Lose a life on an exploded mine and restart when all lives are gone
- Pan and zoom across the infinite board
- Track score, lives, and game status in the HUD

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
3. Open the app in your browser at http://localhost:4200/

## Build

To create a production build, run:

```bash
npm run build
```

## Tests

Run the test suite with:

```bash
npm test
```
